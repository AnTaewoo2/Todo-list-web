# Todo List Web

## Open the site

Open `index.html` in a modern web browser. The site runs directly in the browser without a separate build or server step.

## Manage tasks

- **Add task:** Enter a task in the input field and choose **Add task**.
- **Complete:** Mark a task as finished using its completion control.
- **Remove:** Delete a task using its **Remove** control.

The interface includes an animated visual treatment that adds movement and visual feedback while you use the task list.

## Runtime requirement

React and ReactDOM are loaded from external browser CDNs. An internet connection is required when opening the site unless those resources are replaced with local copies.
